# SQL Daily Practice – MCQ Collection

A structured collection of **SQL multiple-choice questions (MCQs) with answers**, created to support regular SQL practice, concept revision, and self-assessment.

The repository contains topic-focused question sets in Microsoft Word (`.docx`) format. Each set presents questions with four answer choices and indicates the correct option, making it useful for independent learning and quick revision.

## Repository Contents

| File | Description |
|---|---|
| `SQL MCQS 2(ANSWERS).docx` | MCQs covering SQL indexes, including normal, unique, and primary indexes |
| `SQL MCQS 4(ANSWERS).docx` | MCQs covering SQL triggers and trigger events |
| `SQL MCQS 5(ANSWERS).docx` | MCQs covering Transaction Control Language (TCL), transactions, COMMIT, ROLLBACK, and SAVEPOINT |
| `SQL MCQS 6(ANSWERS).docx` | Mixed SQL practice covering aggregate functions, keys, subqueries, string and date functions, window functions, CTEs, views, procedures, indexes, triggers, and permissions |
| `SQL MCQS 31(ANSWERS).docx` | MCQs covering stored procedures, their syntax, execution, and parameters |

## Topics Covered

The question sets provide practice across several SQL concepts, including:

- **Indexes:** Normal indexes, unique indexes, and primary keys/indexes
- **Triggers:** BEFORE and AFTER triggers, INSERT, UPDATE, DELETE events, and row-level execution
- **Transactions (TCL):** `COMMIT`, `ROLLBACK`, `SAVEPOINT`, and auto-commit
- **Stored Procedures:** Creating and calling procedures, parameters, and reusable SQL logic
- **Querying and Functions:** Aggregate functions, subqueries, string functions, and date functions
- **Advanced SQL:** Common Table Expressions (CTEs), window functions, and ranking
- **Database Objects and Security:** Views, keys, and `GRANT`/`REVOKE` concepts

## How to Use This Repository

1. Download or clone the repository.
2. Open any `.docx` question set using Microsoft Word, Google Docs, or another compatible document editor.
3. Read each question and choose an answer before checking the indicated correct option.
4. Review the related SQL concept whenever you answer incorrectly.
5. Revisit the question sets periodically to reinforce your understanding.

> **Practice tip:** Try answering the questions without looking at the marked answers first. Where possible, write and execute a small SQL example to verify your understanding.

## Learning Objectives

By working through these MCQs, learners can:

- Strengthen their understanding of core and intermediate SQL concepts.
- Revise SQL syntax and commonly used database operations.
- Identify gaps in their knowledge through self-assessment.
- Build confidence for SQL tests, technical interviews, and practical database work.

## Requirements

- A document reader that supports `.docx` files, such as Microsoft Word or Google Docs.
- Basic familiarity with SQL is helpful.
- A SQL database environment is optional but recommended for testing queries and examples.
